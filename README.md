# American Liberty Party — Fictional Campaign Website

A fictional presidential campaign website created for a BYU-Idaho political science class assignment. This is an educational simulation, not an actual political party or campaign.

## Pages
- `index.html` — party branding and candidate overview
- `platform.html` — ten platform planks
- `strategy.html` — four campaign strategy sections
- `reflection.html` — individual reflections (complete with your partner before submission)

## Local preview
Open `index.html` using VS Code Live Server or another static local server.

## GitHub Pages
In repository Settings → Pages, select **Deploy from a branch**, branch `main`, folder `/(root)`.
